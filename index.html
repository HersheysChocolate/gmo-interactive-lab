REAL-WORLD CONTEXT

Crop Examples

Different crops can be changed for different reasons. Here are a few real examples behind the ideas in the lab.

🌽
INSECT DEFENSE

Bt maize

Some maize plants make a Bt protein that protects against particular insect pests, such as some caterpillars. It does not protect against every insect.

Simple idea: a feature can target a specific problem.

☁️
INSECT DEFENSE

Bt cotton

Some cotton plants make Bt proteins that work against certain bollworm and budworm pests. Farmers also use ways to slow pests from becoming resistant.

Simple idea: useful traits still need good crop management.

🍚
EXTRA NUTRITION

Golden Rice

Golden Rice was developed to produce beta-carotene in the edible grain. The body can use beta-carotene to make vitamin A.

Simple idea: some crop features are designed to affect food nutrition.

HOW TO READ THE LAB

A learning model, not a field test

The score is an invented 0–100 example. It combines the settings you choose with an assumed feature benefit, so you can see how conditions may change a result.

  • Insect risk changes the example insect-damage pressure.
  • Water available changes the example water-stress pressure.
  • Trait effect changes how strongly the chosen feature helps in this model.

Important: scores are not measured yields or nutrient levels. The DNA marker is a visual aid, not the location of a real gene.

THINK LIKE A SCIENTIST

Three useful questions

  1. Which crop and which feature are being discussed?
  2. Does the feature help with this specific challenge?
  3. What conditions or management choices could change the result?

These questions help separate a real crop example from the simplified score in the demo.
